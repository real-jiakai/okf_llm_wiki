# Models

The current Claude model lineup, one concept file per model. Anthropic also ships a Claude 5 family above the Opus tier (Claude Fable 5, and Claude Mythos 5 via Project Glasswing) — see [anthropic.com](https://www.anthropic.com/news/claude-fable-5-mythos-5).

* [Claude Opus 4.8](./claude-opus-4-8.md) - Anthropic's most capable Opus-tier model for long-horizon agentic work.
* [Claude Sonnet 5](./claude-sonnet-5.md) - Best speed/intelligence balance; near-Opus quality on coding at Sonnet cost.
* [Claude Haiku 4.5](./claude-haiku-4-5.md) - Fastest and most cost-effective model for simple tasks.
